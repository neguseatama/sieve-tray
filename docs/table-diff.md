# 表の比較（`docs/table-diff.md`）

Sieve Tray 2.3.1（Canon）。この文書は `table-diff` コマンドの読み込み、
状態の分類、処理記録の中身を定める。既知の例は §4（KV-C3）で、文書から
読み戻すテスト（`tests/test_canon_docs.py`）が確かめる。

---

## 1. 読み込み

- 2 つの CSV（A と B）を、`normalize` と同じ規則で読む
  （`docs/normalize-format.md` §2: 文字コードは自動判定しない。BOM か
  UTF-8 のときだけそのまま読み、それ以外は `--from-encoding-a` /
  `--from-encoding-b` の指定があったときだけ読む）。
- 読んだ表は、CSV の正規化（同文書 §6）と同じ形に整えてから比べる。
  処理記録に載る A と B のチェックサムは、**この整えた形**の SHA-256
  である。
- キー列は、列の**名前**で指定する（1 つ以上・`--key id` または
  `--key id,region`）。キー列が A か B のどちらかにないときは、
  終了符号 2 で拒否する。

## 2. 状態（閉じた 5 種）

| 状態 | 意味 |
| --- | --- |
| `same` | キーが同じで、共通の列の値がすべて同じ |
| `changed` | キーが同じで、共通の列に違う値がある |
| `removed` | A にだけある |
| `added` | B にだけある |
| `duplicate_key` | A または B でキーが重複している。このキーの行は**比較しない** |

- 列の違い: A にだけある列・B にだけある列は列名で報告し、**共通の列
  だけ**を比較する。
- セルのない位置（列数の少ない行）は空の値として扱う。

## 3. 処理記録と報告

- `handoff/table-diff-receipt.json` には、状態ごとの件数・列の違いの
  件数・A と B の（整えた形の）チェックサムだけが載る。
  **値・キーの値・列名は `handoff/` に出ない**（キー列は番号で載る）。
- `local/table-diff-report.html` に、行ごとの状態と、`changed` の列名と
  A / B の値が出る。
- 終了符号: 表が一致すれば 0・違いがあれば 1（changed / removed / added /
  duplicate_key のどれかが 1 以上。duplicate_key の行は比較しないが、
  一致ではない）。キー列の欠落・読み込みの拒否など、実行できない場合は 2
  （2.3.0 では違いがあっても 0 だった）。

## 4. 既知の例（KV-C3）

表 A（`id,v` の 2 列・行は `1,x` と `2,y`）と表 B（同じ 2 列・行は
`1,y` と `3,z`）、キーは `id`:

- `same` 0・`changed` 1（キー 1 の v が x → y）・`removed` 1（キー 2）・
  `added` 1（キー 3）・`duplicate_key` 0。
- A の整えた形の SHA-256:
  `sha256:3f23e65da769b361ebb9ee59026463fcc1b119b5d787b53599f4f92d4b5fc1e5`
- B の整えた形の SHA-256:
  `sha256:0ff0dc06ae3c3a145949f0349b566e34c2be2004f8f88eca0d0aefa6a96e5cb6`

## 5. 主張の範囲

`table-diff` は「このキーで突き合わせると、この分類の行がこの件数」
という観測だけを示す。どちらの表が正しいか、どちらを優先するかは
示さない。
